## 3. Disconnect Between Historical Disasters and Database Records

A foundational finding of this audit is the temporal dislocation between ground-truth landslide events and the SQLite database:
1. **Documented GSI Ground-Truth Disasters**:
   - The 17 GSI disasters (Tupul Railway, Melthum Quarry, Haflong Station, Dzudza NH-29, Mangan, Bhalukpong, etc.) occurred between **May 16, 2022 and October 4, 2024**.
   - These events are cataloged in `data/raw/historical_landslides_ner.csv` and `data/processed/phase5b_temporal_full.csv`.
2. **Database Recording Window**:
   - `data/observations/pahad_observations.db` began logging on **September 10, 2026**.
   - The database contains **zero historical observations from 2022, 2023, or 2024**.
3. **Implication for V3 Sequence Mechanism**:
   - The previous `v3` training pipeline did not extract time series from `pahad_observations.db`.
   - Instead, `build_33f_sequence()` in `train_lstm_v3.py` took single summary rows from `phase5b_temporal_full.csv` (which had static aggregate numbers for 2022–2024 events) and mathematically synthesized 72-hour antecedent curves backwards in time using polynomial linspace formulas.
   - The user's directive to cease using `build_33f_sequence()` is completely validated by this audit: `build_33f_sequence()` was performing synthetic backward trajectory construction rather than reading true historical telemetry.
