## 1. Cross-Service Failure & Recovery Protocol Matrix

| Failure Domain | Detection Mechanism | Fallback Behavior | Confidence Impact | Emergency Safety Gate | Autonomous / Supervised Recovery |
|:---|:---|:---|:---:|:---:|:---|
| **Weather (IMD / Open-Meteo)** | HTTP connect/read timeout (> 3.5s), HTTP 429/500, or socket error. | Falls back to local in-memory SQLite cache (TTL: 30 min) or district climatological monsoon baseline. Provenance tagged `[CACHED]` or `[HISTORICAL]`. | Data Quality drops from 1.0 to $\le 0.85$. Confidence tagged `MODERATE` or `LOW_CONFIDENCE`. | **Fail-Closed**: Prevents blind alert escalation. Does not generate unconfirmed RED warnings. | Auto-reconnects on next polling cycle. Provenance restored to `[LIVE]` upon valid HTTP 200 payload. |
| **Seismic (NCS / USGS)** | NCS REST API timeout (> 5.0s) or non-200 HTTP code. | Transparently fails over to USGS Global FDSN GeoJSON endpoint for NER bounding box. If USGS also offline, sets ground shaking proxy PGA = 0.0. | Zero impact if USGS succeeds. Defaults to baseline ambient vibration if both fail. | **Fail-Closed**: Zero PGA assumed on double failure. Seismic trigger weight carries zero load. | Continuous background health checks probe NCS every 5 min. Restores live PGA on recovery. |
| **Earth Observation (Sentinel-1 InSAR)** | Copernicus CDSE OData API latency (> 8.0s) or orbit repeat interval gap (> 12 days). | Serves latest processed LOS interferometric deformation raster from local PostGIS store. | InSAR contribution tagged `[HISTORICAL]` prior; does not claim real-time radar acquisition. | **Fail-Closed**: Static slope geometry and pore-water pressure carry physical mechanics. | Periodically checks CDSE catalog every 6 hours; downloads next available SLC product. |
| **Edge IoT (LoRa Telemetry)** | CRC-16 checksum failure, bit flips, node heartbeat timeout (> 120s), or battery cutoff. | Corrupted packet dropped immediately (`ValueError: CRC-16 mismatch`). Sensor slot marked `MISSING`; imputed with conservative training median. | Telemetry marked `MISSING` with `imputed=True`. Confidence downgraded. | **Fail-Closed**: Missing sensor readings are never interpreted as confirmed stability. | Node sends valid CRC-16 packet; restored to `ONLINE` in gateway telemetry registry. |
| **Database (PostgreSQL / Neon)** | Socket connect timeout (> 2.0s), pool exhaustion, or DNS resolution failure. | Application catches exception; `/api/health` returns HTTP `503 DEGRADED`. Read-only corridor geometries served from `CORRIDOR_REGISTRY` in memory. | Persistence disabled; live inference operates entirely in-memory. | **Fail-Closed**: Incident submissions buffered locally in memory/SQLite queue; UI displays degraded banner. | Connection pool worker retries handshake with exponential backoff. Status flips to `200 UP` on reconnect. |
| **Model (PAHAD ML Classifier)** | Missing `.pkl` artifact, feature dimension mismatch, or classification runtime exception. | System catches exception; falls back to physical Mohr-Coulomb Factor of Safety ($FoS$) predictor and empirical I-D rainfall curves. | `model_status` reports `DEGRADED`. Event probability set to unobserved or conservative baseline. | **Fail-Closed**: Physical geotechnical physics continues independently. Human review required. | Model supervisor reloads validated artifact from disk upon file validation. |
| **Malformed / Non-Finite Telemetry** | NaN, Inf, -Inf, or non-numerical string in sensor ingestion or override payload. | Detected in `_assemble_features`. Value marked `UNAVAILABLE` with `imputed=True`. Numerical training median imputed. | Data Quality drops to `DEGRADED DATA`. Uncertainty confidence forced to `LOW_CONFIDENCE` ($\le 0.35$). | **Fail-Closed**: Explicitly suppresses alert escalation (`alert_eligible = False`) to prevent spurious dispatches. | Recovers to nominal confidence upon arrival of finite, verified numerical observations. |
| **External Network Outage** | External DNS failure or socket error on all outbound interfaces. | Platform operates completely locally. Ingests LoRa gateway packets, evaluates FoS, reads local DEM rasters, and persists to local SQLite. | Provenance tagged `[CACHED]` or `[HISTORICAL]`. External feeds marked `UNAVAILABLE`. | **Fail-Closed**: Local sirens and EOC displays operate; external cloud sync deferred. | Resumes external API ingestion and triggers bidirectional sync upon WAN reconnection. |
| **MQTT / Edge Protocol** | Broker TCP disconnection, duplicate sequence number, or replayed packet. | Gateway deduplicates packets via `(node_id, sequence)` ring buffer. Expired or duplicate frames dropped. | Telemetry time series remains strictly monotonic. | **Fail-Closed**: Duplicate sensor packets cannot double-count rainfall or inflate displacement. | Gateway reconnects to local broker; pending buffer flushed in chronological sequence. |
| **Authority Authorization** | Missing authority token, expired cryptographic token, role mismatch, or single-officer signoff. | Action rejected with HTTP 401/403 or `PermissionError`. Alert remains locked in `READY_FOR_AUTHORIZATION` or `AUTHORITY_REVIEW`. | Status remains pending. Audit log records rejected attempt. | **Fail-Closed**: Physical sirens cannot sound; public broadcast cannot be dispatched. | Certified Incident Commander authenticates with valid cryptographic token (`AUTH-v1`). |
| **Notification Gateway** | SMS telecom provider HTTP 500, gateway timeout, or siren relay hardware uncontactable. | Notification Engine marks SMS as `FAILED / RETRYING`, siren marked `DRY_RUN_EMULATOR`. Alternate channels (EOC web dashboard, email) engaged. | Delivery journal records granular status per channel (`SENT`, `FAILED`, `SIMULATED`). | **Fail-Closed**: System never fakes "DELIVERED" status. Watermarks test alerts. | Retry manager executes exponential backoff (1s, 2s, 4s, max 3 retries). Dispatches fallback channel. |
| **Mobile / Offline Field Client** | Mobile device loses cellular connection in steep terrain during hazard inspection. | Field worker client queues incident report locally with client token (`PN-OFFLINE-XXXX`). Automatically syncs on reconnect. | Client UI indicates `QUEUED_OFFLINE`. Server assigns authoritative tracking reference on sync. | **Fail-Closed**: Server enforces idempotent deduplication (`Duplicate: true`) to prevent double-incident creation. | On network restoration, sync manager pushes queue. Server responds with unified batch acknowledgements. |

## 2. Verification Protocol

Every failure vector in this matrix was actively exercised and validated during the execution of `scripts/phase11f_e2e_verification.py`. All fail-closed gates behaved with complete fidelity: zero unhandled 500 crashes, zero unauthorized state jumps, zero falsified delivery receipts, and zero bypasses of the statutory dual-key authority review protocol under the Disaster Management Act 2005.

### Multi-Signal Corroboration Caveat:
The multi-modal corroboration mechanism is an operational engineering heuristic (**2-of-3 Multi-Signal Corroboration Heuristic**). Geotechnical FoS, hydrologic precipitation, and in-situ displacement indicators are complementary streams that co-vary with monsoonal rainfall; they are not assumed to be statistically independent.
