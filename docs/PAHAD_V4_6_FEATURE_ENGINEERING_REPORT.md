## 1. Feature Engineering Objectives

While synoptic models (Stream A) operate on 24-hour to 168-hour macroeconomic weather and hydrological reanalysis, imminent slope failure (0h to 6h) exhibits distinctive **high-frequency physical kinematic precursors**:
1. Sharp non-linear spikes in pore water pressure ($u_w$).
2. Rapid acceleration in borehole shear displacement ($\ddot{\delta}$).
3. Sudden angular rotational deflection of bedrock blocks ($\dot{\theta}, \ddot{\theta}$).
4. Intense bursts of short-duration rainfall overwhelming subsurface drainage channels.

Phase V4.6 derives these features deterministically from sliding chronological windows.

## 2. Derived Feature Specifications

### 2.1 Piezometer Kinematics (`PIEZOMETER`)

| Feature Key | Formula / Computation | Physical Unit | Description |
| :--- | :--- | :--- | :--- |
| `pressure` | Latest calibrated reading $P_t$ | $\text{kPa}$ | Instantaneous pore water pressure |
| `pressure_delta_5m` | $P_t - P_{t-5\text{m}}$ | $\text{kPa}$ | 5-minute pressure change |
| `pressure_delta_15m`| $P_t - P_{t-15\text{m}}$ | $\text{kPa}$ | 15-minute pressure change |
| `pressure_delta_1h` | $P_t - P_{t-1\text{h}}$ | $\text{kPa}$ | 1-hour pressure change |
| `pressure_velocity` | $\frac{P_t - P_{t-\Delta t}}{\Delta t_{\text{hours}}}$ | $\text{kPa/h}$ | Instantaneous rate of pressure rise |
| `pressure_acceleration` | $\frac{v_t - v_{t-\Delta t}}{\Delta t_{\text{hours}}}$ | $\text{kPa/h}^2$ | Acceleration of pore water pressure rise |
| `rolling_mean` | $\frac{1}{N} \sum_{i=1}^N P_i$ | $\text{kPa}$ | Mean pressure over active sliding buffer |
| `rolling_std` | $\sqrt{\frac{1}{N}\sum (P_i - \bar{P})^2}$ | $\text{kPa}$ | Fluctuating noise / turbulence measure |

### 2.2 Inclinometer Shear Kinematics (`INCLINOMETER`)

| Feature Key | Formula / Computation | Physical Unit | Description |
| :--- | :--- | :--- | :--- |
| `displacement` | Latest cumulative shear $\delta_t$ | $\text{mm}$ | In-place cumulative shear offset |
| `displacement_delta` | $\delta_t - \delta_{t-15\text{m}}$ | $\text{mm}$ | 15-minute incremental shear movement |
| `velocity` | $\frac{\delta_t - \delta_{t-\Delta t}}{\Delta t_{\text{hours}}}$ | $\text{mm/h}$ | Borehole shear strain rate |
| `acceleration` | $\frac{v_t - v_{t-\Delta t}}{\Delta t_{\text{hours}}}$ | $\text{mm/h}^2$ | Tertiary creep acceleration precursor |

### 2.3 Tiltmeter Bedrock Kinematics (`TILTMETER`)

| Feature Key | Formula / Computation | Physical Unit | Description |
| :--- | :--- | :--- | :--- |
| `tilt_magnitude` | $|\theta_t|$ or $\sqrt{\theta_{x}^2 + \theta_{y}^2}$ | $\text{degrees}$ | Scalar resultant surface tilt deflection |
| `tilt_rate` | $\frac{\theta_t - \theta_{t-\Delta t}}{\Delta t_{\text{hours}}}$ | $\text{deg/h}$ | Angular deflection velocity |
| `tilt_acceleration` | $\frac{\dot{\theta}_t - \dot{\theta}_{t-\Delta t}}{\Delta t_{\text{hours}}}$ | $\text{deg/h}^2$ | Angular toppling / rotational acceleration |

### 2.4 Rain Gauge Burst Metrics (`RAIN_GAUGE`)

| Feature Key | Formula / Computation | Physical Unit | Description |
| :--- | :--- | :--- | :--- |
| `rainfall_intensity` | Instantaneous rate $R_t$ | $\text{mm/h}$ | Current precipitation rate |
| `rainfall_5m` | Accumulation in last 5 minutes | $\text{mm}$ | Flash deluge indicator |
| `rainfall_15m` | Accumulation in last 15 minutes | $\text{mm}$ | Flash deluge indicator |
| `rainfall_1h` | Accumulation in last 1 hour | $\text{mm}$ | IMD cloudburst threshold check |
| `rainfall_3h` | Accumulation in last 3 hours | $\text{mm}$ | Short-term antecedent precipitation |
| `rainfall_6h` | Accumulation in last 6 hours | $\text{mm}$ | Subsurface saturation loading |
| `rainfall_acceleration`| $\frac{R_t - R_{t-\Delta t}}{\Delta t_{\text{hours}}}$| $\text{mm/h}^2$| Intensification rate of storm cell |

## 3. Provenance & Lineage Preservation

Every feature block generated by `compute_kinematic_features()` attaches complete audit lineage:
- `source_sensor`: Originating instrument ID.
- `sample_count`: Number of raw observations in the calculation buffer.
- `window_seconds`: Total temporal span between oldest and latest sample.
- `provenance`: Invariant badge (`[LIVE]`, `[SIMULATED]`, `[BENCH]`).
- `generated_at`: ISO 8601 UTC timestamp of derivation execution.
